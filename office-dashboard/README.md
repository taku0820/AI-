# ミニ会社ダッシュボード

React + Tailwind CSS + lucide-react で構築した、ジオラマ風オフィスで人が動くインタラクティブダッシュボードです。

## セットアップ・起動

```bash
cd office-dashboard
npm install
npm run dev
```

ブラウザで `http://localhost:5173` を開いてください。

## 機能

- ヘッダー: 現在のやる事 / 進捗率（+87%のような表示）、進捗率スライダー、データ更新ボタン
- 中央: Isometric風のオフィスフロアマップ（開発チーム / デザイン室 / 会議室 / 休憩スペース）
- 12人のドットキャラクターがデスク・会議室・休憩スペースの間をランダムに移動
  - 進捗率が高いほど移動が速く・活発に、低いほど一部の人が座ったまま動かなくなる
- サイドパネル: 実行中のタスク一覧、リアルタイムのアクティビティログ
