# 起動方法（ローカル専用）

```
source venv/bin/activate
python app.py
```

- 既定ポート: `5050`（`http://127.0.0.1:5050`）
- ポートを変更したい場合は環境変数 `PORT` で上書き可能:
  ```
  PORT=5077 python app.py
  ```
- `PORT` が未設定、または数値以外・範囲外（1〜65535外）の場合は、安全に既定の `5050` にフォールバックします。
- ホストは常に `127.0.0.1` に固定されており、外部ネットワークには公開されません（`0.0.0.0` にはバインドしません）。

## ポート運用方針

ポート `5000` は macOS の AirPlay Receiver（ControlCenter）が使用しているため、AI Hive はデフォルトで `5050` を使用します。AirPlay Receiver 自体の設定変更は行っていません。
