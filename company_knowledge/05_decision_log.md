# 判断記録テンプレート

各媒体で確認した数字と、それに対してどう判断したかを記録するための様式です。
実際のデータや推測値はまだ入れず、空のテンプレートとしてここに置いています。
記録するときは、このファイルをコピーするか、下の様式に沿って新しい記録を追記して
使ってください。

数字の定義は [`04_metrics.md`](04_metrics.md)、判断の最終実行者については
[`00_company_rules.md`](00_company_rules.md) を参照してください。

## 記録の様式

1件につき、次の項目を記録します。

- **日付**：確認した日（例：YYYY-MM-DD）
- **媒体**：ROOM／楽天アフィリエイト／note／Pinterest／Threads など
- **観測した数字**：確認できた実際の数字（項目名と値）
- **判断**：その数字をどう受け止めたか（良い・悪いの断定ではなく、気づきや状況の整理）
- **次にすること**：判断を踏まえて、次に試したいこと・確認したいこと
- **保留理由**：まだ判断・実行を保留する場合、その理由

## 記録テンプレート（コピーして使用）

```
### 記録日：

- 日付：
- 媒体：
- 観測した数字：
  -
- 判断：
- 次にすること：
- 保留理由：
```

## 記入時の注意

- 観測した数字は、実際にその媒体の管理画面などで確認できたものだけを書きます。
  未確認の項目は空欄のままにするか、「未確認」と書きます。
- 数字だけを根拠に「成功」「失敗」と断定しないでください。判断欄には、状況の整理や
  気づきを書くようにします。
- 反応がまだ少ない場合は、無理に次の行動を決めず、「保留理由」に反応待ちである旨を
  書いて、様子を見ることも選択肢のひとつです。
